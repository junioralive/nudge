# Architecture

The Worker serves the PWA and Hono API. D1 is the source of truth for tasks, workspaces, settings, push devices, and notification delivery records. Cron claims due delivery sequences atomically. Each active device receives its own delivery and retry state.

Gemini is optional voice. Embedded Memories uses its own `MEMORY_DB`, `MEMORY_VECTORIZE`, `MEMORY_CONFIG_KV`, Workers AI binding, and `MemoriesMCP` Durable Object. It preserves a hard storage boundary from exact task state. Memory failures never block task operations.

Email is an optional in-process module. The Nudge UI, voice allowlist, and `/email/mcp` Durable Object share the same encrypted `EMAIL_KV` account store and native IMAP/SMTP mail service. Nudge stores only stable email-to-task references in D1; mailbox credentials remain in encrypted KV/mail-provider boundaries. Ordinary email requests are on-demand. During an explicitly approved delegation, Cron polls only that exact thread every five minutes and stores its bounded audit transcript encrypted in D1. Email and Memories MCP use the owner-only Nudge Access audience but retain separate Durable Objects and protocol sessions.

WhatsApp is an optional bridge to a user-hosted GOWA REST server. Nudge stores its HTTPS URL, Basic Auth credentials, device ID, and webhook secret as one encrypted `integration_secrets` record. Ordinary chat metadata and message bodies are fetched on demand. Sending and delegation activation use signed, single-use approvals. Active delegations accept only HMAC-verified direct-chat webhook events, use per-conversation locks and Cron recovery, and retain an encrypted audit transcript. Delegated WhatsApp and Email content never enters Memories automatically. WhatsApp has no MCP endpoint in this release.

Delegated conversations are separate from tasks and scheduled automations. They have strict duration/reply caps, source-specific state, encrypted content, deterministic external-identifier hashes, and deduplicated events. Gemini receives only the approved objective, the selected thread, and minimal retrieved context. It cannot change recipients, limits, or tools. Consequential requests always transition to `needs-you` before any reply is sent.
